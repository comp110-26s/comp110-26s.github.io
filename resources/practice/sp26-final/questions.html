Functions

A function’s return value is whatever it evaluates to when called. If no explicit return is written, the function returns: a) 0 b) "" c) None d) False
SHOW SOLUTIONS c) None
In the signature def add(x: int, y: int) -> int:, the -> int specifies: a) the types of the parameters b) the type of the return value c) a default value d) a type error
SHOW SOLUTIONS b) the type of the return value
Parameters are the names in the function’s definition. Arguments are the values passed in at the call site. a) True b) False
SHOW SOLUTIONS a) True
When a function is called, Python creates a new ____ on the call stack to hold its local variables. a) heap b) frame c) object d) module
SHOW SOLUTIONS b) frame
Local variables declared inside a function are accessible from outside the function after it finishes. a) True b) False
SHOW SOLUTIONS b) False
A function that only prints a value but does not return it will, when called in an expression, evaluate to: a) the printed string b) None c) 0 d) a SyntaxError
SHOW SOLUTIONS b) None
The line that declares a function’s name, parameters, and return type is called the function’s: a) body b) docstring c) signature d) prototype
SHOW SOLUTIONS c) signature

While Loops

A while loop whose condition is always True and whose body never breaks out will: a) raise a SyntaxError b) run forever (infinite loop) c) run once d) skip its body entirely
SHOW SOLUTIONS b) run forever (infinite loop)
A while loop first evaluates its condition: a) after each full iteration only b) before every iteration (including the first) c) only once at the start d) only once at the end
SHOW SOLUTIONS b) before every iteration (including the first)
Combining a counter variable with a while loop lets you simulate a count-controlled loop to iterate over a data structure. a) True b) False
SHOW SOLUTIONS a) True
Which of the following is most likely to cause an infinite loop? a) A while whose condition is always False b) A while whose body never changes the variables used in its condition c) A while inside a function
SHOW SOLUTIONS b) A while whose body never changes the variables used in its condition

Runtime

A linear search through an unsorted list of length n has what worst-case runtime? a) O(1) b) O(log n) c) O(n) d) O(n2)
SHOW SOLUTIONS c) O(n)
A nested for loop where both loops run n times yields which runtime? a) O(n) b) O(nlog n) c) O(n2) d) O(2n)
SHOW SOLUTIONS c) O(n2)
Big-O notation describes how runtime grows as input size n: a) decreases b) stays fixed c) grows very large d) changes by constant factor
SHOW SOLUTIONS c) grows very large

Unit Tests

A pytest test function must be defined starting with the prefix: a) check_ b) verify_ c) test_ d) pytest_
SHOW SOLUTIONS c) test_
assert x == y will raise an AssertionError when: a) x == y is True b) x == y is False c) x is y is True d) x is None
SHOW SOLUTIONS b) x == y is False
Running pytest in a directory discovers tests by looking at: a) files and functions whose names begin with test_ b) every .py file in the folder c) only files ending in _tests.py d) the contents of a tests.json manifest
SHOW SOLUTIONS a) files and functions whose names begin with test_
